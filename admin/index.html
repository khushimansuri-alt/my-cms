Quick theme

Used through CSS variables (--primary, --bg, --text, --font, --radius) in theme.css.

Upload a theme (.zip)

Upload a zip of HTML/CSS/JS/images. After it reads the zip, click Import & Activate Everything to set the stylesheet and publish every page in one go — index.html becomes your home page, and every other file becomes a page named after itself (e.g. about.html → /p/about/). Prefer to apply files one at a time instead? Use the buttons under each file below.

Users

Invite a user

The person needs a free GitHub account: GitHub sends the access invitation to that account, and the login instructions are emailed to the address above (set up EmailJS in Settings to send it automatically). There is no separate password — each person logs in with their own GitHub token.

Plugins

Add a plugin

A plugin is a small JavaScript file. Your code runs with a CMS object available: CMS.registerTab({id,label,icon,render(container)}) adds a new sidebar section you control; CMS.commit(files,message), CMS.readText(path), CMS.readJson(path,fallback), CMS.msg(text), CMS.pickPhoto(cb) and CMS.slug(text) are also available. Plugins load automatically each time you log in, or click Reload Plugins above.

Invitation emails (EmailJS)

To email invitations to any address: sign up free at emailjs.com → Email Services: add your Gmail → Email Templates: create one with To Email {{to_email}}, Subject {{subject}}, Content {{message}} → paste the Service ID, Template ID and Public Key (Account → General) below.

Tools

Sitemap helps Google find your pages (needs the Live site URL above). Backup downloads every file of your site.

Works on Cloudflare Pages and Netlify.

Danger Zone

Resets your website: deletes every page, every post and everything in Trash, resets the theme, and replaces your homepage with a blank "Welcome to your CMS" page. Media, Users and this Settings info are kept. This cannot be undone.
